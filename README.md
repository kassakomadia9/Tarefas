# Tarefa 5 – Sistema de Registo de Nascimentos e Identificação de Recém-Nascidos

## Sobre o projecto

Este projecto consiste no desenvolvimento de um sistema simples em Python para o registo e controlo dos nascimentos ocorridos durante o mês de Outubro numa unidade hospitalar.

## Funcionalidades

- Registar os dados da mãe e do recém-nascido.
- Atribuir automaticamente um número sequencial de identificação ao bebé.
- Identificar o género do recém-nascido.
- Associar cada nascimento ao médico responsável pelo parto.
- Consultar os dados do bebé através do número de identificação da mãe.
- Listar todos os nascimentos registados.
- Calcular o número total de nascimentos.
- Apresentar a distribuição dos bebés por género.
- Identificar a quantidade de nascimentos associados a cada médico.

## Tecnologias utilizadas

- Python 3
- Listas e dicionários
- Funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Ciclos de repetição (`for` e `while`)

## Objectivo

Aplicar os conhecimentos fundamentais da linguagem Python na construção de uma solução informática para organizar e consultar informações relacionadas com o registo de nascimentos.
