
#Sistema de Registo de Nascimentos e Identificação de Recém-Nascido.
O projecto permite registar os dados das mães e dos bebés nascidos durante o mês de Outubro, atribuir automaticamente um número de identificação a cada recém-nascido, consultar os dados através do identificador da mãe e apresentar estatísticas dos nascimentos por género, bem como identificar os médicos responsáveis pelos partos.
